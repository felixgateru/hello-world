# Hello World

## Overview

A simple static HTML site with no frameworks or build tools required. This project demonstrates the fundamentals of web development with pure HTML and CSS.

## Getting Started

Open `index.html` directly in your browser — no server or dependencies needed.

Simply:
1. Clone this repository
2. Open `index.html` in your favorite web browser
3. That's it!
